# ⚡ WebP Express (v2.0 PRO) — Bulk Image to WebP Converter

A high-performance, ultra-modern, 100% client-side web application to batch convert images (PNG, JPG, JPEG, GIF, BMP, TIFF, AVIF, SVG) to the high-efficiency **WebP** format entirely in your browser with real-time Before/After split comparison, dimension scaling, and instant ZIP downloads.

## 🚀 Quick Start (Zero Setup Needed)

Simply open **`index.html`** in any modern web browser:

1. Double-click **`index.html`** (or right-click → *Open with Chrome / Edge / Firefox / Safari*).
2. **Drag & Drop** your images into the dropzone, click to browse, or press **`Ctrl+V`** to paste from clipboard.
3. Set your desired **Quality** (5–100%, default 80%) or use quick presets (Aggressive, Small, Balanced, High, Lossless).
4. *(Optional)* Expand **Advanced Controls** to resize/scale dimensions or specify a filename suffix.
5. Click **"Convert All to WebP"**.
6. Compare quality with the **Interactive Split-Screen Slider**, or click **"Download All as ZIP"**.

## ✨ Key Features & Style Highlights

- 🎨 **Luxe Glassmorphism 3.0 UI**: Luminous floating mesh glow, ambient blur, glowing border beams, and sleek micro-interactions.
- 🌓 **Dynamic Theme Switcher**: Instant toggle between Deep Midnight Dark Mode and Crisp Light Pearl Mode (with saved preference).
- 🔍 **Interactive Before / After Split Comparison Slider**: Compare visual clarity side-by-side between the original image and converted WebP.
- 📋 **Direct Clipboard Paste Support**: Hit `Ctrl + V` anywhere on the page to immediately convert screenshots or copied images.
- 📐 **Advanced Dimension Rescaling**: Choose scale percentages (100%, 85%, 75%, 50%) or fit within maximum dimensions (1920px Full HD, 1280px HD, 800px Web).
- 🔒 **100% Client-Side Privacy**: Zero server uploads. All image decoding, resizing, and WebP encoding happen securely in browser memory.
- ⚡ **Full Alpha Channel Transparency**: Preserves PNG transparent layers without artifacting or black background fill.
- 📊 **Live Stats Dashboard**: Instant metrics on total images processed, original vs converted sizes, and percentage space saved.
- 📦 **Batch ZIP Packaging**: Bundles all converted files in one `.zip` archive via JSZip.
- 🎛️ **Dual View Modes**: Switch effortlessly between Card Grid view and List view.
